# File formats

## Brian/open_questions.txt

Plain text, UTF-8. The artifact shows Brian this file as written, and Brian reads the `Case:` line for the case name. A full example: [examples/open_questions_MOCK.txt](examples/open_questions_MOCK.txt).

```
OPEN QUESTIONS FOR CASE CONTEXT INTERVIEW
Case code: <CODE>
Case: <project name> - <client>
Case scope (as found in files): <one line>
Case period (as found in files): <YYYY-MM-DD> to <YYYY-MM-DD>
SharePoint folder: <case folder name>
Generated by: Claude Code review of the SharePoint file tree
Generated on: <YYYY-MM-DD>
Files reviewed: <n> (<main types>)

How to read this file: each question has an ID, the question, what the review found, and the files it relates to. Questions are ordered by theme, most important first.

== Theme A: <theme> ==

Q01
Question: <one question, answerable in a few sentences>
Context found: <what the files show, with numbers, dates and document names>
Related files: <path relative to the case folder> ; <path>

Q02
...
```

Rules: IDs are `Q` plus two or more digits, unique and never reused. Paths are relative to the case folder, separated by ` ; `, or `none`.

## Brian/raw_transcripts/<YYYY-MM-DD>_<CODE>_<id8>.txt

The same layout as the artifact's "Save transcript" button, plus the interviewee's name when sync can resolve it.

```
BRIAN CASE CONTEXT INTERVIEW - TRANSCRIPT
Case code: <CODE>
Case: <case name>
Interview: <id8>
Interviewee: <display name, or "Team member">
Interview started: <YYYY-MM-DD HH:MM>
Transcript saved: <YYYY-MM-DD HH:MM>
Messages: <n>
Merged into case context: <yes, on YYYY-MM-DD | no>

Speakers: "Brian" is the AI interviewer; "Interviewee" is the case team member.
Each settled question ends with a "Recorded for Qnn:" line.

============================================================

[Brian] <YYYY-MM-DD HH:MM>
<message>

[Interviewee] <YYYY-MM-DD HH:MM>
<message>
Attached: <file name> (asset <asset id>)

...
```

Times are local time. Write message text exactly as stored; don't summarize or correct it.

## Brian/context.md

Written by Brian when an interview is merged (structure in [template/context_prompt.txt](template/context_prompt.txt)) and mirrored by `/brian sync`. Never edit it by hand.

## Brian/brian.json

```json
{
  "caseCode": "<CODE>",
  "caseName": "<project name> - <client>",
  "artifactUrl": "https://claude.ai/artifact/<id>",
  "createdAt": "<YYYY-MM-DDTHH:MM:SSZ>",
  "lastReview": "<YYYY-MM-DDTHH:MM:SSZ>",
  "lastSync": "<YYYY-MM-DDTHH:MM:SSZ or null>"
}
```
